# HENGSHI Jarvis

HENGSHI Jarvis is the private collaboration workspace for Jarvis Box and Create Jarvis.

## Access Model

- `hengshi-jarvis/jarvis-box` and `hengshi-jarvis/create-jarvis` are private paid-collaboration repositories.
- Repository access requires commercial onboarding and an invitation as a member of the `hengshi-jarvis` GitHub organization.
- Public Jarvis Box releases remain available through `hengshi/jarvis-box` and official HENGSHI delivery channels.
- For onboarding or repository access, contact hi@hengshi.com.

## 协作方式

- `hengshi-jarvis/jarvis-box` 与 `hengshi-jarvis/create-jarvis` 均为私有付费协作仓库。
- 访问源码仓库前，需要完成商务开通，并受邀加入 `hengshi-jarvis` GitHub 组织。
- Jarvis Box 的公开发布物继续通过 `hengshi/jarvis-box` 与衡石官方交付渠道提供。
- 开通或协作访问请联系 hi@hengshi.com。
